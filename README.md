# Fabrizio Sola — Links
Landing page estática para Instagram. Incluye los cinco perfiles indicados.

## Publicación en Vercel
1. Crear un repositorio nuevo en GitHub y subir `index.html` a la raíz.
2. Entrar a https://vercel.com/new e importar el repositorio.
3. Elegir Framework Preset: Other (o sin framework), Root Directory: `./`, y Deploy.
4. Copiar la URL permanente `*.vercel.app` y agregarla en Instagram > Editar perfil > Enlaces.

No necesita paquetes, variables de entorno ni comandos de build.

## Fotos de perfil
El archivo usa identificadores gráficos originales en lugar de fotos de perfil porque las URLs de imágenes de Instagram pueden caducar y las imágenes originales no estaban disponibles en esta conversación. Se pueden reemplazar los elementos `.profile` por imágenes locales una vez obtenidas de cada cuenta.
